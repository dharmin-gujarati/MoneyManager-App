# 💰 Money Manager App (iOS)

A modern personal finance management application built using **SwiftUI** and **SQLite**. The app helps users track income, expenses, manage categories, and monitor their financial activities through a clean and user-friendly interface.

---

## ✨ Features

- 🔐 User Login & Signup
- 💵 Add Income & Expense Transactions
- ✏️ Edit Existing Transactions
- 🗂️ Create and Manage Categories
- 📊 Financial Dashboard
- 💾 Local SQLite Database Storage
- ⚙️ Settings Screen
- 🚀 Splash Screen
- 📱 Native SwiftUI Interface

## 🚀 Getting Started

### Requirements

- macOS
- Xcode 15+
- iOS 16+

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/MoneyManager_app.git
```

2. Open

```
MoneyManager_app.xcodeproj
```

3. Build and Run

- Select an iOS Simulator or physical device.
- Press **⌘ + R**.

---

## 📖 Usage

1. Create an account or log in.
2. Add income or expense transactions.
3. Create custom categories.
4. Edit or delete transactions.
5. View your financial overview.
6. Manage app settings.
